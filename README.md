# Herdeiro da Chama

Jogo de plataforma 2D em **Phaser 3**, desenvolvido como projeto pessoal utilizando IA em praticamente todas as etapas — game design, arte e programação.

> "Construa um mundo que pareça existir há mil anos. O jogador verá apenas uma pequena parte dele."

## Status do projeto

🚧 Em desenvolvimento — documentação macro (00–08) completa, primeiro Vertical Slice (Vila Inicial) documentado. Código-base (scaffold) em andamento.

## Stack

- [Phaser 3](https://phaser.io/) — engine
- [Vite](https://vitejs.dev/) — bundler / dev server
- JavaScript (ES Modules)
- Deploy: GitHub Pages, via GitHub Actions

## Rodando localmente

```bash
npm install
npm run dev
```

## Metodologia

O jogo é desenvolvido por **Vertical Slice**: cada bioma (região do continente) é tratado como um mini-projeto isolado, com documentação própria antes de qualquer asset ou código ser produzido. Documentação completa mantida separadamente.
