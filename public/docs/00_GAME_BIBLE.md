# Visão do Projeto

**Herdeiro da Chama** é um jogo de plataforma 2D desenvolvido em **Phaser**, criado como um projeto pessoal de aprendizado utilizando Inteligência Artificial em praticamente todas as etapas do desenvolvimento.

O objetivo não é criar o maior jogo possível.

O objetivo é criar um jogo completo, polido e memorável.

Toda decisão de design deve priorizar qualidade, simplicidade e consistência.

---

# Pilares do Projeto

## 1. Gameplay primeiro

A história existe para fortalecer a jogabilidade.

Nunca o contrário.

Toda mecânica precisa ser divertida antes de ser complexa.

---

## 2. Simplicidade vence

Sempre escolher a solução mais simples.

O projeto será desenvolvido praticamente por uma única pessoa.

Escopo controlado é prioridade.

---

## 3. Exploração recompensa

O jogador deve sentir vontade de explorar.

Sempre deve existir algo escondido:

- caminhos secretos
- pequenas histórias
- NPCs
- colecionáveis
- Brasas
- Crônicas

Explorar deve valer a pena.

---

## 4. Mundo antigo

O continente deve transmitir a sensação de que existiu muito antes do protagonista nascer.

Ruínas.

Templos.

Pontes quebradas.

Castelos abandonados.

Símbolos esquecidos.

Tudo deve contar uma história.

---

## 5. Magia rara

A magia existe.

Mas poucas pessoas realmente a conhecem.

Por isso cada manifestação mágica deve causar impacto.

# Estrutura do Mundo

O jogo é dividido em grandes biomas.

Cada bioma possui:

- identidade visual própria
- inimigos próprios
- NPCs
- mini-boss
- boss
- uma Brasa Primordial
- uma nova habilidade
- novas informações sobre a história

Cada bioma representa um avanço tanto na gameplay quanto na narrativa.

---

# Progressão

O jogador começa extremamente simples.

Ao recuperar cada Brasa Primordial ele desperta uma nova habilidade.

Essas habilidades desbloqueiam novas possibilidades de exploração e combate.

O jogador nunca recebe poderes desnecessários.

Cada habilidade precisa possuir aplicação prática durante todo o restante do jogo.

---

# Direção Narrativa

A história nunca será contada diretamente.

Ela será descoberta através de:

- exploração
- NPCs
- Crônicas ilustradas
- ruínas
- símbolos
- ambientes

O jogador monta a história como um quebra-cabeça.

---

# Direção Cinematográfica

O jogo não possui cutscenes animadas.

Toda narrativa importante será apresentada através das **Crônicas**.

Cada Crônica utiliza:

- imagem ilustrada
- zoom lento
- pequenos movimentos de câmera
- fade
- texto narrado
- transições simples

Inspirado nas introduções de Elden Ring e Dark Souls.

---

# Interface de Diálogos

Os diálogos devem ser simples.

Características:

- caixa de diálogo única
- retrato do NPC
- retrato do protagonista quando necessário
- texto aparecendo gradualmente
- botão para acelerar o texto
- botão para avançar a próxima frase
- diálogos curtos
- sem grandes blocos de texto

---

# Direção Artística

Pixel Art.

Visual inspirado em RPGs clássicos modernos.

Cada bioma possui:

- fundo exclusivo
- paleta própria
- iluminação própria
- ambientação única

A identidade visual deve permitir que o jogador reconheça imediatamente em qual região está.

# Regra de Ouro

Nenhuma funcionalidade será implementada antes de existir documentação.

Toda decisão importante deve ser registrada.

O projeto deve permanecer simples, consistente e possível de ser concluído.

---

# Objetivo Final

Entregar um jogo curto, divertido e completo.

Um projeto capaz de demonstrar boas práticas de desenvolvimento utilizando Inteligência Artificial como ferramenta de criação.

Mais importante do que adicionar dezenas de mecânicas é terminar um jogo que conte uma boa história, tenha identidade própria e seja divertido do início ao fim.
