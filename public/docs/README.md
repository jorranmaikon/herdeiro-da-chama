# Herdeiro da Chama — Documentação

> "Construa um mundo que pareça existir há mil anos. O jogador verá apenas uma pequena parte dele."

Documentação oficial e viva do projeto. Toda decisão de design, gameplay, arte e arquitetura técnica nasce e é validada aqui antes de virar asset ou código.

## Metodologia

O jogo é desenvolvido por **Vertical Slice**: cada bioma (região do continente) é tratado como um mini-projeto isolado, com documentação própria, seguindo o [Template de Vertical Slice](09_TEMPLATE_VERTICAL_SLICE.md), somente depois que toda a documentação macro (00–08) está fechada.
